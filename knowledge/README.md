# Knowledge Base

## Folders

- `_inbox/` — Drop zone for raw documents (Word, PDF, notes). Processed into subfolders, originals stay as archive.
- `prompting/` — Prompt engineering techniques, frameworks (INSANE, Ottley, PDER), meta-prompting, optimization
  - `templates/` — Copy-ready reference prompts (inbound, outbound, production examples)
- `testing/` — Testing methodology, route-based testing, client testing workflow
- `vapi/` — VAPI-specific documentation, API guides, configuration references
- `elevenlabs/` — ElevenLabs setup, v2 voice list with IDs
- `general/` — Agent types (inbound/outbound), flow architecture, do's and don'ts
- `compliance/` — GDPR, HIPAA, SOC2, AI Act overview and practical compliance path

## How to add new knowledge

1. Drop your raw document into `_inbox/`
2. Ask Claude to process it into the appropriate subfolders
3. The original stays in `_inbox/` as a source archive
